# 让社区成员复测同一条路线

打开修订室，选择 **网页试玩 → 苔港 → 开始网页试玩**。内置练习会检查任务文字，打开背包、核对标题，再收起背包。打开 **证据画面** 查看每一步的实机截图，或在总览下载证据包。

## 换成自己的游戏

1. 在本机启动游戏的开发服务。对于没有构建步骤的 HTML 小游戏，可以在游戏目录执行 `py -3 -m http.server 8000 --bind 127.0.0.1`。
2. 在修订室选择 **自定义路线**，填入游戏网址，如 `http://127.0.0.1:8000/index.html`。
3. 展开 **查看或编辑操作步骤**，填写路线名称、窗口尺寸和最多十步操作。若界面由 Canvas 绘制，用按键推进并留图；文字和元素检查适用于可定位的网页元素。

```json
{
  "name": "背包标题与操作提示",
  "viewport": [1280, 720],
  "steps": [
    {"label": "打开背包", "action": "key", "key": "Tab"},
    {"label": "核对标题", "action": "text", "selector": ".inventory h1", "text": "旅行背包"},
    {"label": "检查面板边界", "action": "visible", "selector": ".inventory"}
  ]
}
```

| 操作 | 参数 | 检查内容 |
| --- | --- | --- |
| capture | 无 | 记录当前窗口 |
| key | key | 按一次键，如 Escape |
| hold | key, ms | 按住 1 到 5000 毫秒 |
| click | selector | 点击可定位的元素 |
| text | selector, text | 等到元素可见且包含指定文字 |
| visible | selector | 检查元素完整落在当前窗口内 |

修订室只接受带端口的本机网址。每次启动独立的 Edge 浏览器会话。首个失败会结束路线，并尽可能保留现场。修改游戏后在原报告点 **载入路线复测**，再点 **开始网页试玩**。将两轮报告或可公开的截图随问题提交，可让维护者对照相同条件下的表现。

Rustfire 预设需要另外启动该游戏的本机服务。发布包附带的是可独立运行的苔港练习。
